# Invitation fonts

The invitation serves its fonts locally. Each family includes its SIL Open Font License.

| File | Family | Upstream source |
| --- | --- | --- |
| `BodoniModa.woff2` | Bodoni Moda, variable optical size and weight | [Google Fonts / Bodoni Moda](https://github.com/google/fonts/tree/main/ofl/bodonimoda) |
| `GreatVibes-Regular.woff2` | Great Vibes, including Cyrillic | [Google Fonts / Great Vibes](https://github.com/google/fonts/tree/main/ofl/greatvibes) |
| `Roboto.woff2` | Roboto, variable width and weight | [Google Fonts / Roboto](https://github.com/google/fonts/tree/main/ofl/roboto) |
| `ScheduleTinos-Regular.woff2` | Tinos Regular, Latin and Cyrillic subset for the schedule | [Tinos project](https://github.com/googlefonts/tinos) |

The schedule uses Times New Roman when available and loads Tinos as a fallback.
